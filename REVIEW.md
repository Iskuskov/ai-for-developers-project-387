# Критерии ревью календаря

Предметные инварианты поведения, которые независимый ревьюер обязан проверять на каждом PR.
Каждое замечание обязано содержать: **файл, строку, условия ошибки и её последствие**.
Форматирование проверяет линтер — в ревью не повторяется.
Если подтверждённых дефектов нет — ревьюер сообщает об этом прямо.

## Инварианты

1. **Занятый слот не остаётся доступным.** После создания Записи её слот не возвращается `GET /slots` как доступный — ни для того же типа, ни для других. Последствие нарушения: двойное бронирование одного времени.

2. **Пересечения интервалов запрещены.** Включая частичное наложение записей разных типов. Встреча может начинаться в момент окончания предыдущей. Последствие: два гостя на одном звонке.

3. **Сетка стартов.** Старты слотов — на 30-минутной сетке рабочих часов 09:00–18:00 Europe/Moscow. Слоты вне сетки или рабочих часов не предлагаются. Последствие: запись вне рабочих часов владельца.

4. **Окно записи 14 дней.** Даты вне 14-дневного окна (сегодня + 14, Europe/Moscow, окно сдвигается со временем) дают пустой список слотов. Последствие: запись за пределами окна.

5. **Длительность слота.** Равна `durationMinutes` выбранного типа встречи. Последствие: несоответствие ожиданию гостя и владельца.

6. **Удалённый тип не ломает гостя.** Удалённый тип исчезает со страницы `/booking`; старая прямая ссылка `/booking/:id` показывает дружелюбное сообщение «Этот тип встреч больше не доступен для записи», а не падение. Последствие: сломанная страница гостя.

7. **Валидация записи.** Имя гостя — до 100 символов; email валиден по контракту. Нарушение — единая ошибка `ApiError`, а не падение. Последствие: мусорные записи.

8. **Список записей — только предстоящие.** `GET /bookings` скрывает прошедшие Записи, сортировка по времени старта. Последствие: владелец видит неактуальный список.

## Процессные критерии (не поведение, но ревью проверяет)

- Сгенерированные файлы (`spec/tsp-output/`, `frontend/src/shared/api/`) меняются только вместе с правкой `spec/main.tsp` — дрейф контракта недопустим.
- Изменение не выходит за согласованный объём спеки; выход за объём — замечание с указанием пункта спеки.
